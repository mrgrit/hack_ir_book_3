## 2장 추가 검증 — 2026-11-04

2장 집필에서 전용 인덱스 적재와 실제 UI 촬영을 수행했다. 아래 2026-11-03 기록의 미수행 범위는 1장 당시의 기록이다.

- Ubuntu Python 3.10.12에서 파일 검사·새 인덱스 적재를 수행했다. 실제 indexer 노드 버전은 OpenSearch 2.16.0이다. 루트 응답의 호환 버전 7.10.2와 구분했다.
- `book3-r01-pilot01`에 85,306건을 적재하고 14개 조회의 응답을 저장했다. `tools/verify_chapter02.py`로 원본 이벤트와 다시 대조했다. 웹 로그는 34,018건이며 후보 연결은 2,262건·75일, 10월 30일 503건이다.
- 실제 Wazuh의 인덱스 패턴·Discover·Dev Tools·막대그래프 화면을 촬영하고 본문에 5개 화면으로 배치했다. 전용 패턴과 그래프를 보존했다.
- 새 적재 도구의 방어 조건 6개를 Ubuntu에서 통과했다. 로컬 전체 시험은 10개 중 9개 통과, `BOOK3_SOURCE` 미설정으로 통합 생성 시험 1개 skip이다. 이번 시험과 아래 1장 당시의 skip 없는 통합 시험을 구분한다.
- 49쪽을 렌더해 개별 지면을 확인했다. 마지막 화면 자르기·필드 표기 수정으로 바뀐 9·19·28쪽을 다시 열었고 나머지 46쪽은 픽셀 동일성을 확인했다. DOCX 내장 이미지·원본 자산 해시, 전체 URL과 복사용 쿼리를 대조했다.
- 기존 인덱스의 소멸·재생성·건수 감소는 없었다. 실제 공격·PCAP 재생·규칙 설치·예약 모니터·원상복구 삭제는 수행하지 않았다. 1·2권, REV01, 강의 추적 파일은 수정하지 않았다.

상세 근거는 `chapter02-review.md`, 원본 조회 응답은 `chapter02-query-results.json`, 오프라인 대조는 `chapter02-data-verification.json`, 산출물 검사는 `chapter02-artifact-verification.json`을 따른다.

## 1장 당시 기록 — 2026-11-03

## 실제 수행

- 원본 커밋 d6a2397fc31517147ddd09f58e0d153bc8cf0588의 Python 코드·프로파일·README와 강의 365개 슬라이드의 내용을 대조했다. 슬라이드 텍스트를 추출해 실습 번호와 장별 목표를 대응시켰다.
- 실제 XLSX 3개의 34,425행을 읽기 전용으로 분석했다. 원본 식별자·개별 행은 공개 산출물에 넣지 않았다. 날짜별 통계와 31,479개 출발지의 최신 행 합집합을 구분했다.
- 13개 라운드의 7·30·90·365일 시나리오와 R01·R02·R08·R15의 90일 스트림을 생성했다. 원본 코드를 수정하지 않았고 모듈 로딩 시 Windows epoch 호환 처리를 적용했다.
- unittest 4개를 skip 없이 통과했다. R01 두 번 생성의 바이트 해시·manifest 일치, 전역 시간순·기간·건수·정답 조인, 기존 결과 거부, 부적절한 인수 거부, 변조 감지, R08 경계 밖 10건의 명시를 검사했다. 이 통합 시험에서 socket.create_connection을 차단했다.
- R01 pilot01은 85,306건(배경 83,044, 시나리오 2,262)이었다. 첫 시각은 2026-08-03T00:00:21.234+0900, 마지막은 2026-10-31T23:58:42.101+0900이다. 원본의 시각 역전 17건을 정렬한 출력에서 전역 단조 증가를 확인했다.
- B5 원본 11쪽을 열어 확인하고 첫 구역의 판형·여백·테마를 상속했다. 초안 렌더의 강제 쪽 나눔·표 배치를 교정한 뒤 최종 DOCX 22쪽을 검수했다. 변경 없는 쪽은 PNG 바이트 동일성으로 이전 개별 검수와 연결했다. 소설 예시 본문은 제거했고 별도 장 파일만 만들었다.
- 인물 삽화의 원본과 DOCX 지면을 각각 확인했다. 어깨·팔꿈치·손목·손의 연결, 두 팔·두 손, 케이블과 카트의 지지, 노트북 방향, 투명 여백과 종횡비를 확인했다. 도식은 실제 UI를 대신하지 않는다.

기계 검사 결과와 현재 산출물 해시는 artifact-verification.json, 생성기 상세 결과는 generator-probes.json, 표본 결과는 sample-statistics.json에 있다. 검수 PDF·쪽별 PNG·대용량 생성 파일은 build에만 있다.
