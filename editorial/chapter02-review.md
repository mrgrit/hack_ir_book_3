## 강의 해석과 호환성 수정

- `agent.name`은 관측 출처, `data.src_ip`는 네트워크 출발지이다. 웹 로그의 `data.srcip`와 필드 철자가 다르다. 해당 인덱스의 문자열은 keyword이며 임의로 `.keyword`를 붙이지 않는다.
- hits.total의 gte 10000과 Terms의 버킷 건수를 구분했다. 전체 건수는 track_total_hits로 확인한다. 반환 상위 후보, sum_other_doc_count와 오차 상한을 설명했다.
- cardinality는 추정치이다. 이번 고정 데이터의 정확한 집합 계산과 일치했으나 일반적인 1~2% 보증으로 서술하지 않았다. 요청 수를 고유 IP 수로 나눈 값의 단위도 명시했다.
- 7일 fixed_interval의 시작은 조회 시작일과 다를 수 있다. 첫 7월 30일 버킷과 마지막 10월 29일 버킷의 부분 기간을 설명했다. 날짜 출력 format과 충돌한 extended_bounds 문자열은 실제로 동작하는 epoch 밀리초 정수로 고쳤다.
- Python 3.10에서 `+0900` 시각을 읽도록 `check_dataset.py`에서 UTC 오프셋을 정규화했다. 기존 파일 검사의 해시·기간 조건은 유지했다.
- bucket_selector는 Terms가 반환한 후보에 적용한다. 직접 조회와 예약 monitor·trigger·action은 구분한다. 생성기의 rule 필드를 manager가 만든 경보로 표현하지 않았다.
- 실측 표본의 시간 단위가 미확정인 상태를 유지했다. 이번 장은 생성기의 R01 시간 모델을 분석하며 실세계 분포 보정이 완료되었다고 주장하지 않는다.
