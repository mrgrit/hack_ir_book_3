## 해석 교정

1. HTTP 200·500을 SQL 실행·유출 확정으로 쓰지 않았다. 본문은 요청·응답 본문·WAF 정책·DB 기록을 확보할 대상으로 연결한다. 응답 크기 합계에는 정상·오류·중복 전송이 포함될 수 있다.
2. 같은 IP의 403·200 공존 집계와 시각 순서를 구분했다. 원본 Q6의 전체 90일 조회에 집중 활동일 조건을 추가했다. 14:00에도 200이 있으므로 처음 200을 우회 성공 시각으로 단정하지 않았다.
3. 원본 R03 모니터는 설명의 “같은 사이트”를 실제로 묶지 않으며 명시적 시간 범위도 없다. 본문에서 서비스·시간을 고정한 후보 조회와 순서 확인을 제시했다. 경보 설치·자동 차단은 시험하지 않았다.
4. R04 배율 0.005에서 업로드 추가는 12건이다. 원강의 수천 건이라는 규모를 옮기지 않았다. 고유 URL 21개와 파일 1개를 구분했다. 명령 인자가 포함된 URL은 실제 요청하지 않았다.
5. audit의 parent·exe·auid 및 웹의 duration_ms는 생성기가 붙인 필드이다. full_log에 모두 포함되어 실제 디코딩되었다고 주장하지 않았다. 웹과 audit의 0.05초 고정 차이도 생성 설계로 설명했다.
6. 등록 명령은 `*/10 * * * *`이지만 생성 반복문은 3,600초씩 증가한다. 관측은 937개, 최초 2026-09-22 23:00:01.972부터 최종 2026-10-31 23:00:00.890 KST까지이다. 이 불일치를 수집 장애로 해석하지 않았다. 원본 보존을 위해 이 장에서 시간 모델을 바꾸지 않았으며 경험 분포에 맞춰 보정했다고 주장하지 않는다.
7. FIM 파일 변경·계정 생성과 키 접속·부팅 실행 성공을 구분했다. 대응은 조사표의 제안이며 합성 경로를 실제 kt66 파일로 간주해 조치하지 않는다.

## 지면과 자산

B5 30쪽을 개별 검수했다. 표 열 너비·도구 소개 순서·화면 crop을 수정하고 변경 지면을 다시 확인했다. 미변경 지면은 픽셀 비교로 최초 개별 검수와 연결했다. 전체 URL 6개, 쿼리 12개, 명령 6개와 내장 그림 해시는 `chapter04-artifact-verification.json`에 기록한다.

인물 삽화는 1권의 검수된 `assets/illustrations/natural-angle/black-web-input.png`를 변경 없이 복사했다. 원본을 직접 열어 어깨·팔꿈치·손목·두 손의 연결, 왼손 키보드·오른손 마우스, 의자·골반·다리, 모니터 방향을 확인했다. 후드 상의의 검은 여우 패치를 유지했다. 관계 도식 1개와 실제 UI 1개를 추가했다.

선택 원상복구 DELETE는 실행하지 않았다. 전용 두 인덱스는 검토용으로 보존한다. 신규 VM 설치부터의 재현·실제 manager 규칙 평가·PCAP·격리 효과·강의 원본의 모든 규칙 실행은 이번 확인 범위에서 제외한다.

## 저자용 재생성

독자용 준비·생성·검사·적재는 `examples/chapter04/commands.sh`와 본문을 따른다. 자료와 응답을 확보한 뒤 다음 명령을 순서대로 사용한다. 조판에는 본문의 실제 화면과 검수된 삽화 파일이 필요하다.

```bash
python3 tools/queries_chapter04.py
python3 tools/verify_queries.py 4 build/r03-ch04 build/r04-ch04
python3 tools/figures_chapter04.py
python3 tools/write_chapter04.py
python3 tools/build_docx.py --source manuscript/volume03-chapter04.json --output manuscript/volume03-chapter04.docx
```

DOCX를 렌더하고 전체 지면을 검수한 뒤 `tools/verify_artifact.py 4 <검수용 PDF> --reviewed-all-pages`로 최종 파일 해시와 내장 자산·URL·복사용 입력을 대조한다. 쿼리 응답을 갱신하지 않고 생성 조건을 바꾸면 데이터 검증은 실패해야 한다.
